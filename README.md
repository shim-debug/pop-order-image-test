# pop-order-image-test

POP用紙オンライン発注システム(pop_order_gas)の商品画像表示方式比較検証用リポジトリです。

現行のGoogle Drive→Base64方式に対し、GitHub Pages上のHTTPS画像を直接読み込む方式で
初期表示速度・画像表示速度・応答データ量がどれだけ改善するかをテスト用デプロイ限定で
比較検証するために使用します。本番環境・本番デプロイとは無関係です。

## 画像ファイル命名ルール

`images/` 配下に「商品コード.jpg」の命名規則で配置します(例: `P01.jpg`)。
13商品すべて`image/jpeg`であることを確認済みのため、拡張子は`.jpg`に統一しています。
